# Wifituner - optimize your Wi-Fi connection.

## Windows
```cmd
git clone https://github.com/peerawatm/wifituner.git
cd wifituner
python tuner.py
```

## macOS/Linux
```bash
git clone https://github.com/peerawatm/wifituner.git
cd wifituner
python3 tuner.py
```
